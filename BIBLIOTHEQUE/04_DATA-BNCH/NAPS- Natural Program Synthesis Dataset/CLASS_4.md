# NAPS: Natural Program Synthesis Dataset (2018)
Source: NAPS- Natural Program Synthesis Dataset.md

## Core reasons
- The paper's primary contribution is a new dataset for program synthesis, positioned as a resource with collected problem statements and solutions.
- It emphasizes dataset scale/splits and uses baseline models only to gauge dataset difficulty, making evaluation infrastructure secondary.

## Evidence extracts
- "We present a program synthesis-oriented dataset consisting of human written problem statements and solutions for these problems." (Section Abstract)
- "Dataset contains 2231 training and 485 test examples, with additional 16410 unlabelled examples for pretraining and data augmentation." (Section 1. Introduction)
