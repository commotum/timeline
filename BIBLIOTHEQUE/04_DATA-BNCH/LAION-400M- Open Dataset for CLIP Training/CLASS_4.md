# LAION-400M: Open Dataset of CLIP-Filtered 400 Million Image-Text Pairs (Not specified in the paper)
Source: LAION-400M- Open Dataset for CLIP Training.md

## Core reasons
- The paper's main contribution is the public release of a large-scale image-text dataset with CLIP filtering, embeddings, and kNN indices, which is data infrastructure rather than a modeling proposal.
- It frames the release as closing a data availability gap for training vision-language models, with model training only used as a proof of concept.

## Evidence extracts
- "we build and release for public LAION-400M, a dataset with CLIP-filtered 400 million image-text pairs, their CLIP embeddings and kNN indices that allow efficient similarity search." (Abstract)
- "By releasing an openly available dataset that contains 400 million image-text pairs, we have closed the gap to proprietary large scale datasets that were necessary to train state-of-the-art language-vision models such as DALL-E and CLIP." (4 Conclusion)
