## Summary
Point-BERT defines pretext tasks for 3D point cloud representation learning, including dVAE point cloud reconstruction, masked point modeling, mixed token prediction, and an auxiliary contrastive objective. It evaluates downstream 3D point cloud tasks for object classification, few-shot classification, part segmentation, and transfer learning to ScanObjectNN. Across tasks, inputs are 3D point clouds or spatial patches with fixed-size sampling in the reported setups, while outputs range from discrete tokens/features to class labels and per-point labels. Attention is standard self-attention and state is constructed via learned representations (both inferred).
