## 2. One-Sentence Contribution Summary

It introduces BEVFormer, which "learns unified BEV representations with spatiotemporal transformers to support multiple autonomous driving perception tasks" for "3D visual perception tasks, including 3D detection and map segmentation based on multi-camera images" (Abstract).

## 6. Input and Representation Constraints

Input resolution: A specific experiment reports a fixed image size ("The input image shape is  $900 \times 1600$ ." Table 6: Latency and performance of different model configurations on nuScenes val set.).
Fixed patch size: Not specified.
Fixed number of tokens / grid size: BEV queries are grid-shaped with fixed H and W ("We predefine a group of grid-shaped learnable parameters  $Q \in \mathbb{R}^{H \times W \times C}$  as the queries of BEVFormer, where H,W are the spatial shape of the BEV plane." 3.2 BEV Queries); default sizes are specified ("the default size of BEV queries is  $200 \times 200$ " 4.2 Experimental Settings; "the default spatial shape of BEV queries is  $300 \times 220$ " 4.2 Experimental Settings).
Fixed dimensionality: The BEV representation is explicitly 2D ("Since the BEV features  $B_t \in \mathbb{R}^{H \times W \times C}$  is a versatile 2D feature map" 3.5 Applications of BEV Features).
Padding or resizing requirements: Not specified.

## 7. Context Window and Attention Structure

Maximum sequence length: Four frames are explicitly used in training ("We denote the timestamps of these four samples as t-3, t-2, t-1 and t." 3.6 Implementation Details), and an ablation includes #Frame = 5 ("| 5      | 0.517 | 0.412 | 0.387              |" Table 7: NDS of models on nuScenes val set using different frame numbers during training.).
Fixed or variable length: Fixed per experiment, with a default of 4 frames ("Therefore, we set the frame number during training to 4 by default in experiments." Appendix C Ablation Studies).
Attention type: Sparse/local deformable attention for spatial cross-attention ("we develop the spatial cross-attention based on deformable attention [56], which is a resource-efficient attention layer where each BEV query  $Q_p$  only interacts with its regions of interest across camera views." 3.3 Spatial Cross-Attention); temporal self-attention also uses deformable attention ("$TSA(Q_p, \{Q, B'_{t-1}\}) = \sum_{V \in \{Q, B'_{t-1}\}} DeformAttn(Q_p, p, V),$" 3.4 Temporal Self-Attention).
Cost-management mechanisms: The design is explicitly motivated by computation limits ("Due to the large input scale of multi-camera 3D perception... the computational cost of vanilla multi-head attention [42] is extremely high. Therefore, we develop the spatial cross-attention based on deformable attention" 3.3 Spatial Cross-Attention), and attention is restricted to regions of interest ("each BEV query  $Q_p$  only interacts with its regions of interest across camera views." 3.3 Spatial Cross-Attention).

Attribution of gains: Improvements are attributed to architectural choices and temporal modeling rather than scale alone ("deformable attention significantly outperforms other attention mechanisms under a comparable model scale." 4.5 Ablation Study; "The effect of temporal information is mainly in the following aspects: (1) The introduction of temporal information greatly benefits the accuracy of the velocity estimation; (2) The predicted locations and orientations of the objects are more accurate with temporal information; (3) We obtain higher recall on heavily occluded objects" 4.5 Ablation Study). Training tricks are also cited ("randomly sampling 4 frames from 5 frames is a effective data augment strategy to improve performance" Appendix C Ablation Studies), and scaling knobs are explicitly ablated ("We ablate the scales of BEVFormer in three aspects, including whether to use multi-scale view features, the shape of BEV queries, and the number of layers, to verify the trade-off between performance and inference latency." 4.5 Ablation Study).

## 11. Architectural Workarounds

Spatial cross-attention via deformable attention to limit computation to regions of interest: "we develop the spatial cross-attention based on deformable attention [56], which is a resource-efficient attention layer where each BEV query  $Q_p$  only interacts with its regions of interest across camera views." (3.3 Spatial Cross-Attention).
Temporal self-attention with recurrent use of history BEV features: "we propose temporal self-attention to recurrently fuse the history BEV information." (Abstract); "Given the BEV queries Q at current timestamp t and history BEV features  $B_{t-1}$  preserved at timestamp t-1... we model this temporal connection between features through the temporal self-attention (TSA) layer" (3.4 Temporal Self-Attention).
Grid-shaped BEV queries to impose a fixed BEV grid: "We predefine a group of grid-shaped learnable parameters  $Q \in \mathbb{R}^{H \times W \times C}$  as the queries of BEVFormer, where H,W are the spatial shape of the BEV plane." (3.2 BEV Queries).
Task-specific heads on shared BEV features: "With the unified features generated by BEVFormer, the model can collaborate with different task-specific heads such as Deformable DETR [56] and mask decoder [22], for end-to-end 3D object detection and map segmentation." (1 Introduction).

### 13. Constraint Profile (Synthesis)

**Constraint Profile:**
- Domain scope: Autonomous driving camera datasets (nuScenes and Waymo) with multi-camera RGB images.
- Task structure: Two perception tasks (3D detection and map segmentation) evaluated, including joint multi-task training.
- Representation rigidity: Fixed grid-shaped BEV queries (e.g., 200 x 200 or 300 x 220) and 2D BEV feature maps.
- Model sharing vs specialization: Shared BEV encoder/backbone with task-specific detection and segmentation heads.
- Role of positional encoding: Learnable positional embedding applied to BEV queries as a fixed default.

### 14. Final Classification

Classification: **Multi-task, single-domain**

Justification: The paper explicitly targets multiple tasks, stating that BEVFormer supports "multiple autonomous driving perception tasks, including 3D detection and map segmentation" and that it is trained with "both detection and segmentation heads" (1 Introduction; 4.4 Multi-tasks Perception Results). Evaluation is on autonomous driving camera datasets ("nuScenes dataset [4] and Waymo open dataset [40]" with "RGB images from 6 cameras"), indicating a single domain and single modality, with no cross-domain transfer claims (4.1 Datasets).
