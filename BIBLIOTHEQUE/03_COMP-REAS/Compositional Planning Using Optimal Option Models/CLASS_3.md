# Compositional Planning Using Optimal Option Models (2012)
Source: Compositional Planning Using Optimal Option Models.md

## Core reasons
- The paper's main contribution is a new planning/computation mechanism: recursively composing option models and deriving generalized Bellman-style model equations.
- It introduces and analyzes an iterative planning algorithm (OOMI) that changes how planning computation is performed across multiple subgoals and abstraction levels.

## Evidence extracts
- "Our fundamental operation is the recursive composition of option models into other option models." (Section Abstract)
- "This algorithm, which we call option-option model iteration (OOMI), can be viewed as a generalisation of value iteration to option models for multiple subgoals." (Section 5 Option-Option Model Iteration)
