## Summary
The paper evaluates sequence prediction over discrete token streams, covering algorithmic counting patterns, memorization, binary addition, and Penn Treebank language modeling. Inputs and outputs are 1D token sequences with variable length, and the stream setup plus expandable/infinite memory implies open dynamics. The models rely on internal hidden state and controllable stack/list memory, supporting constructed state and dynamic attention (inferred from the memory-controller description).
