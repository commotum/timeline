## Summary
The paper evaluates recursive reasoning models on grid-based puzzle tasks: Sudoku-Extreme (9x9 grids), Maze-Hard (30x30 mazes), and ARC-AGI puzzles defined by input-output grid demonstrations. Input domains are 2D grids with Fixed sizes for Sudoku/Maze and Capped sizes for ARC-AGI (up to 30x30), and outputs are grids for Sudoku/ARC-AGI while maze outputs are inferred as paths. Attention is best classified as Static and state as Constructed (both inferred) due to fixed-size interfaces and explicit latent reasoning updates.

- Inference: Mapped the 9x9 grid to 2D with Fixed dynamics; marked attention Static because inputs/outputs have fixed shape "[B, L]"; marked state Constructed from "latent reasoning z" updates.
