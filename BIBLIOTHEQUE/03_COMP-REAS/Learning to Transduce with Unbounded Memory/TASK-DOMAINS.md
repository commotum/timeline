## Summary
The paper evaluates five sequence-to-sequence transduction tasks over symbol sequences: copying, reversal, bigram flipping, SVO to SOV reordering, and genderless to gendered article translation. Inputs and outputs are 1D sequences with explicitly bounded lengths (synthetic tasks sample lengths from unif{8,64} for training; ITG grammars generate lengths 8 to 128), so dynamics are capped. The models use external Stack/Queue/DeQue memories controlled by an RNN, implying dynamic attention and constructed state (inferred from the controller-driven push/pop and memory state descriptions).

- "read an input sequence, and generate as target sequence a transformed version of the source sequence" (Section 4.1 Synthetic Transduction Tasks)
- "The source sequence is copied to form the target sequence." (Section 4.1 Synthetic Transduction Tasks)
- "The length of each training source sequence is uniformly sampled from  $unif\{8,64\}$" (Section 4.1 Synthetic Transduction Tasks)
- Inference: Attention Dynamic and State Dynamic (inferred) because the memory module is "receiving, from the controller, a value  $\mathbf{v}_t \in \mathbb{R}^m$ , a pop signal  $u_t \in (0,1)$ , and a push signal  $d_t \in (0,1)$" and it will "receive as previous state of the stack the pair  $(V_{t-1}, \mathbf{s}_{t-1})$." (Section 3.1 Neural Stack)
