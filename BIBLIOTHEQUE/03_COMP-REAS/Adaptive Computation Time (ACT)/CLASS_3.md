# Adaptive Computation Time for Recurrent Neural Networks (Not specified in the paper.)
Source: Adaptive Computation Time (ACT).md

## Core reasons
- Proposes Adaptive Computation Time so recurrent networks can learn a variable number of computation steps per input rather than fixed-depth inference.
- The main contribution is a halting/pondering mechanism with a time penalty that changes how computation is performed in the model.

## Evidence extracts
- "This paper introduces Adaptive Computation Time (ACT), an algorithm that allows recurrent neural networks to learn how many computational steps to take between receiving an input and emitting an output." (Abstract)
- "Adaptive Computation Time (ACT) modifies the conventional setup by allowing  $\mathcal{R}$  to perform a variable number of state transitions and compute a variable number of outputs at each input step." (Section 2 Adaptive Computation Time)
