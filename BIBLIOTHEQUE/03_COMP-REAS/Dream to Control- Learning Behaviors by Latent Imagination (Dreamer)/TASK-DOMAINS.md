## Summary
Dreamer is presented as a visual continuous control agent that maps image observation streams to continuous action sequences over finite-horizon episodes. The paper also trains a learned world model that constructs latent states and predicts next latent states, rewards, and observations, plus a value model that predicts scalar state values. Inputs and outputs span 2D images, 0D latent vectors/scalars, and 1D temporal action sequences; episode length is capped (1000 steps) and observation images are fixed-size. Attention dynamics are not specified, while state is constructed via learned latent representations.
