# Nyströmformer: A Nyström-based Algorithm for Approximating Self-Attention (2021)
Source: Nystromformer- A Nystrom-Based Algorithm for Approximating Self-Attention.md

## Core reasons
- Proposes a Nyström-based approximation mechanism that replaces standard self-attention with a linear-complexity computation.
- The primary contribution is an algorithmic change to how attention is computed for scalability, not positional encoding or new datasets.

## Evidence extracts
- "To address this limitation, we propose Nyströmformer – a model that exhibits favorable scalability as a function of sequence length. Our idea is based on adapting the Nyström method to approximate standard self-attention with O(n) complexity." (Abstract)
- "In this paper, we propose a O(n) approximation, both in the sense of memory and time, for self-attention." (Introduction)
