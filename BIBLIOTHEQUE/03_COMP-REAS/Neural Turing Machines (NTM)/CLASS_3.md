# Neural Turing Machines (Not specified in the paper.)
Source: Neural Turing Machines (NTM).md

## Core reasons
- Proposes a new computation mechanism that couples a neural controller with an external, addressable memory and differentiable read/write operations, extending standard recurrent computation.
- Frames standard RNNs as lacking practical mechanisms for algorithmic tasks and introduces NTM to enable learning simple algorithms like copying and sorting.

## Evidence extracts
- "We extend the capabilities of neural networks by coupling them to external memory resources, which they can interact with by attentional processes." (Abstract)
- "A Neural Turing Machine (NTM) architecture contains two basic components: a neural network controller and a memory bank." (Section 3 Neural Turing Machines)
