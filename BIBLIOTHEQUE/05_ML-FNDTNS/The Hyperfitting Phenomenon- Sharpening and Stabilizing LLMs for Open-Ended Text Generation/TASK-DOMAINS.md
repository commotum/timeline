## Summary
The paper primarily covers autoregressive generation, with open-ended text continuation as the core task and image generation as an additional modality. It also evaluates downstream language understanding through MMLU (multiple-choice QA) and GLUE (task-oriented NLU classification). The supported domains therefore span 1D (t) token sequences and 2D (x, y) images, with outputs ranging from 1D generated sequences and 2D generated images to 0D answer/label selections. Attention and State labels are inferred from the paper's description of standard Transformer models trained with a next-token prediction objective.

## Evidence
### Task: Open-ended text continuation generation
- "In the setting of open-ended text generation, it is well-documented that LLMs tend to generate repetitive and dull sequences, a phenomenon that is especially apparent when generating using greedy decoding." (ABSTRACT)
- "Each sample consists of a textual context and two possible continuations, with one continuation always coming from the original text and the other generated by a model." (Section 4 OPEN-ENDED TEXT GENERATION)
- "Hyperfitting is observed in the task of sequence generation, where the model's predictions are recursively added to its input." (Section 7.2 RELATIONSHIP TO GROKKING AND DOUBLE DESCENT)
- Inference: `1D (t)`, `Capped`, and `Open` are inferred from token-sequence generation and recursive continuation behavior, supported by fixed context/eval lengths ("we select the first 32 tokens as context"; "trimmed to 256 tokens") and the explicit open-ended framing. `Static` attention and `Direct` state are inferred from "we train the model via the next-token prediction objective" with standard autoregressive Transformer usage (Section 3).

### Task: Autoregressive image generation from partial images
- "Specifically, we fine-tune one instance for each of the following models: Tiny Llama 1.1b, DeepSeek 7b (Bi et al., 2024), Llama 3.1 8b & 70B (Dubey et al., 2024), and ImageGPT-Large (Chen et al., 2020) for image generation." (Section 3 Hyperfitting)
- "Besides using visual tokens, ImageGPT is a standard Transformer architecture and was pre-trained using next-token prediction on 32x32 images." (Section 7.1 IMAGE GENERATION)
- "Figure 6 contains a qualitative comparison of the greedy generation when the models receive the first 25% of an image." (Section 7.1 IMAGE GENERATION)
- Inference: `2D (x, y)` and `Fixed` are inferred from fixed-size CIFAR-10 image completion (32x32) and fixed partial-image prompts ("first 25%"; "first 256 pixels (8 rows)" in Section B.1). `Static` attention and `Direct` state are inferred from the same next-token Transformer setup.

### Task: Multiple-choice question answering (MMLU)
- "We further explore the effect of hyperfitting on downstream tasks using the MMLU (Hendrycks et al., 2021) benchmark and GLUE benchmark (Wang et al., 2018)." (Section B.4 Performance on Downstream Tasks)
- "The MMLU dataset is a benchmark designed to measure a model's acquired knowledge over 57 subjects. This is achieved via a multiple-choice setup, where the candidate answer with the highest predicted probability is interpreted as the model's answer." (Section B.4.1 MMLU)
- "Following the implementation of the official GitHub repository, we vary the number of question-answer pairs in the context and report these separately." (Section B.4.1 MMLU)
- Inference: `1D (t)` and `Capped` input are inferred from tokenized prompt contexts with bounded in-context examples; `0D` and `Fixed` output are inferred from selecting one answer choice per question. `Static` attention and `Direct` state are inferred from reuse of the same hyperfitted models without additional fine-tuning (Section B.4).

### Task: Natural language understanding classification (GLUE)
- "The GLUE dataset tasks the model across a range of different tasks." (Section B.4.2 GLUE)
- "For all these tasks we evaluate the models in both a few-shot and zero-shot setting." (Section B.4.2 GLUE)
- "Table 8: Comparison of the original and hyperfitted Llama and Deepseek models across various GLUE tasks, using 0-shot (0S) and few-shot (FS) configurations. The target metrics are accuracy (acc), F1 score (f1), and Matthews correlation (corr.)." (Section B.4.2 GLUE / Table 8)
- Inference: `1D (t)`/`Capped` input is inferred from prompt-based few-shot/zero-shot text evaluation; `0D`/`Fixed` output is inferred as task decisions used for classification-style evaluation metrics. `Static` attention and `Direct` state are inferred from the same autoregressive model interface used throughout the paper.
