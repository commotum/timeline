## Core reasons
- Proposes an unsupervised NMT training pipeline built on generatively pre-trained language models using few-shot amplification, distillation, and backtranslation.
- Reframes translation as a language modeling task and trains a single model for both translation directions, indicating a methodological contribution to model training.

## Evidence extracts
- "We show how to derive state-of-the-art unsupervised neural machine translation systems from generatively pre-trained language models. Our method consists of three steps: *few-shot amplification, distillation*, and *backtranslation*." (Abstract)
- "In our present work, we cast machine translation as a language modeling task and jointly train and sample generations from a single language model for both source-to-target and target-to-source translation." (Section 3 BACKTRANSLATION VIA LANGUAGE MODELING)
