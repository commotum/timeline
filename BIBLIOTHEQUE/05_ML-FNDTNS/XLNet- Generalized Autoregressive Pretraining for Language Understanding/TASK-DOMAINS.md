## Summary
The paper covers language tasks over text sequences: permutation-based autoregressive pretraining, extractive/answerability question answering, multiple-choice reading comprehension, classification-oriented NLU, and document reranking. Inputs are consistently token sequences and are implemented with capped interfaces (for example, maximum sequence lengths of 512/128 and top-100 reranking candidates). Outputs span token-level outputs (predicted tokens or answer spans), single-label decisions, and ranked lists. Attention is Static and State is Constructed (inferred) from fixed masking rules plus explicit cached-memory reuse in the Transformer-XL recurrence mechanism.

## Evidence
### Task: Autoregressive language modeling (permutation LM pretraining)
- "we propose the permutation language modeling objective that not only retains the benefits of AR models but also allows models to capture bidirectional contexts." (Section 2.2)
- "During pretraining, we always use a full sequence length of 512." (Section 3.1)
- Inference: 1D (t) and Capped are inferred from "sequence" inputs and explicit max length; Static attention is inferred from fixed attention masks over sequence positions; Constructed state is inferred from recurrence memory: "cache the obtained content representations" and "caching and reusing the memory" (Section 2.4).

### Task: Question answering (span extraction and answerability prediction)
- "Many downstream tasks have multiple input segments, e.g., a question and a context paragraph in question answering." (Section 2.5)
- "To finetune an XLNet on SQuAD2.0, we jointly apply a logistic regression loss for answerability prediction similar to classification tasks and a standard span extraction loss for question answering [10]." (Section A.3.2)
- Inference: 1D (t) input/output span structure and Capped dynamics are inferred from sequence-token modeling and finetuning max lengths in Table 8; 0D answerability output is inferred from "logistic regression loss" (Section A.3.2).

### Task: Reading comprehension (multiple-choice selection)
- "Table 2: Comparison with state-of-the-art results on the test set of RACE, a reading comprehension task..." (Section 3.3, Table 2 caption)
- "The RACE dataset [18] contains near 100K questions ... with the answers generated by human experts." (Section A.3.1)
- Inference: output as a single selected option (0D, Fixed) is inferred from the multiple-choice benchmark setup and "Accuracy" reporting for RACE in Table 2; sequence dimension/dynamics are inferred from textual passages/questions and "We use a sequence length of 512 during finetuning." (Section A.3.1).

### Task: Text classification / natural language inference / sentiment analysis
- "...including question answering, natural language inference, sentiment analysis, and document ranking." (Abstract)
- "Following previous work on text classification [39, 23], we evaluate XLNet on the following benchmarks: IMDB, Yelp-2, Yelp-5, DBpedia, AG, Amazon-2, and Amazon-5." (Section A.3.3)
- Inference: classification outputs are treated as 0D Fixed labels; input is inferred as 1D (t) Capped from tokenized single/paired text and max sequence lengths in finetuning Table 8.

### Task: Document ranking (ad-hoc retrieval reranking)
- "Table 2: Comparison with state-of-the-art results on ... ClueWeb09-B, a document ranking task." (Section 3.3, Table 2 caption)
- "...the task is to rerank the top 100 documents retrieved using a standard retrieval method." (Section A.3.5)
- Inference: input/output are modeled as token-sequence query/document representations with ranked-list output; Fixed output dynamics are inferred from reranking a fixed top-100 candidate set.
