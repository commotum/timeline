## Summary
The paper covers program synthesis tasks across three domains: string manipulation, bit-vector manipulation, and circuit transformation. Inputs are SyGuS specifications using input-output examples for strings/bit-vectors and a circuit plus boolean equivalence formula for circuits, and outputs are synthesized programs or circuits. Where described, example counts are bounded in the benchmarks, and program size is variable (inferred); the A* search procedure dynamically selects candidates and maintains explicit search state (inferred).

- "comprises input-output examples given as a logical formula" (Section 2 Overview)

- "the specification comprises between 2 to 400 examples." (Section 5.1 Experimental Setup)
