## Summary
The paper covers a single reinforcement-learning task: policy evaluation as long-term value prediction under off-policy training. The input is a temporal trajectory of transitions, explicitly described as infinite-length, so input dynamics are Open in 1D (t). The output is scalar state-value prediction, while updates continue indefinitely over time (Open out dynamics). The algorithm maintains constructed internal state through eligibility and followon traces, and uses a static consideration pattern at runtime (inferred from fixed update equations).

## Evidence
### Task: Policy evaluation (long-term value prediction)
- "The problem it solves is that of efficiently learning to make a sequence of long-term predictions about how a dynamical system will evolve over time." (Section 1. Parametric Temporal-Difference Learning)
- "Within reinforcement learning, TD learning is typically used to learn approximations to the value function of a Markov decision process (MDP)." (Section 1. Parametric Temporal-Difference Learning)
- "As in the on-policy case, the data is a single, infinite-length trajectory of actions, rewards, and feature vectors generated by a continuing finite Markov decision process." (Section 3. Instability of Off-policy TD(0))
- "\(\boldsymbol{\theta}_t^{\top} \boldsymbol{\phi}(s) \approx v_{\pi}(s)\)" (Section 2. On-policy Stability of TD(0))
- "where  \(F_t \geq 0\)  is a scalar memory called the *followon trace*." (Section 5. The General Case)
- Inference: Attention Dynamic is marked Static (inferred) because the runtime update is fully specified by fixed equations over current transition and carried traces, e.g., "\(\mathbf{e}_{t} \doteq \rho_{t} \left( \gamma_{t} \lambda_{t} \mathbf{e}_{t-1} + M_{t} \boldsymbol{\phi}_{t} \right)\)" (Section 5. The General Case), with no explicit mechanism for runtime observation/retrieval selection. Out Dynamics is marked Open (inferred) because updates are defined "at each of a sequence of time steps \(t = 0, 1, 2, \ldots\)" (Section 2. On-policy Stability of TD(0)) on a "single, infinite-length trajectory" (Section 3. Instability of Off-policy TD(0)).
