# Asynchronous Methods for Deep Reinforcement Learning (2016)
Source: Asynchronous Methods for Deep Reinforcement Learning (A3C).md

## Core reasons
- Proposes an asynchronous gradient descent framework for deep reinforcement learning and positions it as the central contribution.
- Introduces asynchronous variants of standard RL algorithms (including actor-critic), emphasizing training/optimization methodology rather than new data or positional encoding.

## Evidence extracts
- "We propose a conceptually simple and lightweight framework for deep reinforcement learning that uses asynchronous gradient descent for optimization of deep neural network controllers." (Abstract)
- "We now present multi-threaded asynchronous variants of one-step Sarsa, one-step Q-learning, n-step Q-learning, and advantage actor-critic." (Section 4. Asynchronous RL Framework)
