# SATNet: Bridging deep learning and logical reasoning using a differentiable satisfiability solver (2019)
Source: SATNet- Bridging Deep Learning and Logical Reasoning Using a Differentiable Satisfiability Solver.md

## Core reasons
- Proposes a differentiable MAXSAT solver layer to integrate logical reasoning into deep networks, changing the computation mechanism beyond standard feedforward inference.
- Targets missing capability of handling hard logical constraints and learning logical structure end-to-end, which is a reasoning mechanism focus rather than positional encoding or data resources.

## Evidence extracts
- "we propose a new direction toward this goal by introducing a differentiable (smoothed) maximum satisfiability (MAXSAT) solver that can be integrated into the loop of larger deep learning systems." (Abstract)
- "Our key contribution is to develop and derive a differentiable smoothed MAXSAT solver that can be embedded within more complex deep architectures" (Section 1. Introduction)
