# DeLiVoTr: Deep and light-weight voxel transformer for 3D object detection (2024)
Source: DeLiVoTr- Deep and Light-weight Voxel Transformer for 3D Object Detection.md

## Core reasons
- Proposes a transformer-based architecture explicitly for LiDAR point clouds and 3D object detection, adapting attention to voxelized 3D data.
- Uses voxel intra- and inter-region transformer modules to model local and global features in the 3D voxel space, central to handling the higher-dimensional domain.

## Evidence extracts
- "we propose a Deep and Light-weight Voxel Transformer (DeLiVoTr) network with voxel intra- and inter-region transformer modules to extract voxel local and global features respectively." (Abstract)
- "The DeLiVoTr inputs LiDAR point cloud and predicts 3D bounding boxes in an autonomous driving scenario." (Section 3.1. Overview)
