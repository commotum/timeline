## Core reasons
- Proposes a new vision Transformer architecture that integrates convolutions (token embedding and projection) to better model image structure, which is an adaptation of Transformers for the 2D vision domain.
- Centers on architectural changes (hierarchical stages with convolutional components) for image recognition performance and efficiency, rather than positional encoding or dataset creation.
