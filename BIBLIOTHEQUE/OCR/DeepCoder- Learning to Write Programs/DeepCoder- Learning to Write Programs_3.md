# DEEPCODER: LEARNING TO WRITE PROGRAMS (Not specified in the paper.)
Source: DeepCoder- Learning to Write Programs.md

## Core reasons
- Proposes using neural predictions to guide discrete program-search procedures, changing how computation/search is performed for program synthesis.
- Frames a learning-plus-search pipeline where a model predicts program attributes and the search is ordered by those predictions, i.e., a mechanism for reasoning over program space.

## Evidence extracts
- "We use the neural network's predictions to augment search techniques from the programming languages community, including enumerative search and an SMT-based solver." (Abstract)
- "The components of LIPS are (1) a DSL specification, (2) a data-generation procedure, (3) a machine learning model that maps from input-output examples to program attributes, and (4) a search procedure that searches program space in an order guided by the model from (3)." (Section 3)
