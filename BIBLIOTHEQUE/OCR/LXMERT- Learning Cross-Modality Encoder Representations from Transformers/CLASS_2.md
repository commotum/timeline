# LXMERT: Learning Cross-Modality Encoder Representations from Transformers (2019)
Source: LXMERT- Learning Cross-Modality Encoder Representations from Transformers.md

## Core reasons
- Proposes a Transformer-based architecture explicitly designed to combine language and visual inputs via separate and cross-modality encoders, indicating a multimodal adaptation of Transformers.
- Represents images as object sequences paired with word sequences, showing the model lifts Transformers beyond 1D text into visual-language inputs.

## Evidence extracts
- "LXMERT, we build a large-scale Transformer model that consists of three encoders: an object relationship encoder, a language encoder, and a cross-modality encoder." (Abstract)
- "As shown in Fig. 1, our model takes two inputs: an image and its related sentence (e.g., a caption or a question). Each image is represented as a sequence of objects, and each sentence is represented as a sequence of words." (Section 2 Model Architecture)
