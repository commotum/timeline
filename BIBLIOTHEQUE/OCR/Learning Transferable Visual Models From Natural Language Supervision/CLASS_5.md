# Learning Transferable Visual Models From Natural Language Supervision (Not specified in the paper.)
Source: Learning Transferable Visual Models From Natural Language Supervision.md

## Core reasons
- Introduces a pre-training method that learns image representations from natural language supervision by predicting image-text pairings, which is a methodological contribution rather than positional encoding or dimensional lifting.
- Uses the learned text encoder to synthesize zero-shot classifiers for downstream tasks, emphasizing transferable representation learning.

## Evidence extracts
- "We demonstrate that the simple pre-training task of predicting which caption goes with which image is an efficient and scalable way to learn SOTA image representations from scratch on a dataset of 400 million (image, text) pairs collected from the internet." (Abstract)
- "CLIP jointly trains an image encoder and a text encoder to predict the correct pairings of a batch of (image, text) training examples." (Figure 1)
