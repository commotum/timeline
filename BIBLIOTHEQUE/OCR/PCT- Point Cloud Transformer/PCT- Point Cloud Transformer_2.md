## Core reasons
- Introduces a transformer-based framework specifically for point cloud data, emphasizing suitability for an unstructured, disordered 3D domain.
- The main contribution is adapting Transformer architecture (embedding/attention) to point cloud learning tasks rather than proposing new positional encodings.

## Evidence extracts
- "The irregular domain and lack of ordering make it challenging to design deep neural networks for point cloud processing. This paper presents a novel framework named Point Cloud Transformer(PCT) for point cloud learning." (Abstract)
- "We proposed a novel transformer based framework named PCT for point cloud learning, which is exactly suitable for unstructured, disordered point cloud data with irregular domain." (1. Introduction)
