# CoAtNet: Marrying Convolution and Attention for All Data Sizes (Not specified in the paper.)
Source: CoAtNet- Marrying Convolution and Attention for All Data Sizes.md

## Core reasons
- Proposes a new hybrid architecture (CoAtNet) that combines convolution and self-attention as the main contribution, which is an architectural ML contribution rather than a dataset, benchmark, or compute mechanism.
- Focuses on how to merge convolution and attention and stack them to improve generalization and capacity, not on positional encoding changes or higher-dimensional tokenization.

## Evidence extracts
- "we present CoAtNets (pronounced "coat" nets), a family of hybrid models built from two key insights: (1) depthwise Convolution and self-Attention can be naturally unified via simple relative attention; (2) vertically stacking convolution layers and attention layers in a principled way is surprisingly effective in improving generalization, capacity and efficiency." (Abstract)
- "Based on these insights, we propose a simple yet effective network architecture named CoAtNet, which enjoys the strengths from both ConvNets and Transformers." (Section 1 Introduction)
