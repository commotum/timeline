# StoryMem: Multi-shot Long Video Storytelling with Memory (2025)
Source: StoryMem- Multi-shot Long Video Storytelling with Memory.md

## Core reasons
- Proposes an explicit memory mechanism that conditions generation to supply missing long-range consistency across shots.
- Reframes multi-shot generation as iterative shot synthesis using a memory bank, i.e., a computation change rather than a dataset or positional encoding contribution.

- "we propose **StoryMem**, a paradigm that reformulates long-form video storytelling as iterative shot synthesis conditioned on explicit visual memory, transforming pre-trained single-shot video diffusion models into multi-shot storytellers." (Abstract)
