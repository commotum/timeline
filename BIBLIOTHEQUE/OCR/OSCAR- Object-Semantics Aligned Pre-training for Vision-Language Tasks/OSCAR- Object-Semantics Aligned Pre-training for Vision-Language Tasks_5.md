## Core reasons
- Proposes a new vision-language pre-training method focused on improving cross-modal representation learning via object-tag anchors rather than new datasets or positional encoding.
- The contribution is a training/methodological advance for Transformer-based vision-language models, aligning with general ML method development.

## Evidence extracts
- "While existing methods simply concatenate image region features and text features as input to the model to be pre-trained and use self-attention to learn image-text semantic alignments in a brute force manner, in this paper, we propose a new learning method Oscar<sup>1</sup>, which uses object tags detected in images as anchor points to significantly ease the learning of alignments." (Abstract)
- "In this paper, we have presented a new pre-training method OSCAR, which uses object tags as anchor points to align the image and language modalities in a shared semantic space." (7 Conclusion)
