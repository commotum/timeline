# A Distributional Perspective on Reinforcement Learning (2017)
Source: A Distributional Perspective on Reinforcement Learning.md

## Core reasons
- Proposes a foundational shift in reinforcement learning from expected value to modeling the full return distribution, with theoretical analysis of distributional Bellman operators.
- Introduces a concrete algorithmic approach for learning value distributions (discrete/parametric), which is a training-method contribution rather than a dataset or architectural dimension change.

## Evidence extracts
- "we argue for the fundamental importance of the value distribution: the distribution of the random return received by a reinforcement learning agent." (Abstract)
- "We will model the value distribution using a discrete distribution parametrized by $N \in \mathbb{N}$ and $V_{\text{MIN}}, V_{\text{MAX}} \in \mathbb{R}$." (Section 4.1. Parametric Distribution)
