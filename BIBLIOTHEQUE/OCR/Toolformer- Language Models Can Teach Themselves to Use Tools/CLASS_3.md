# Toolformer: Language Models Can Teach Themselves to Use Tools (Not specified in the paper.)
Source: Toolformer- Language Models Can Teach Themselves to Use Tools.md

## Core reasons
- Proposes a mechanism for LMs to decide when and how to call external tools to overcome missing capabilities like factual lookup and calculation.
- Introduces a self-supervised training procedure that changes inference computation by inserting API calls and incorporating tool outputs.

## Evidence extracts
- "A simple way to overcome these limitations of today's language models is to give them the ability to *use external tools* such as search engines, calculators, or calendars." (Section 1 Introduction)
- "We introduce Toolformer, a model trained to decide which APIs to call, when to call them, what arguments to pass, and how to best incorporate the results into future token prediction." (Abstract)
