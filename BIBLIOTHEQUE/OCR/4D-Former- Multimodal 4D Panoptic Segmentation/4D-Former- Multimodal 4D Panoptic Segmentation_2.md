# 4D-Former: Multimodal 4D Panoptic Segmentation (Not specified in the paper.)
Source: 4D-Former- Multimodal 4D Panoptic Segmentation.md

## Core reasons
- Proposes a transformer-based architecture tailored to 4D panoptic segmentation on LiDAR point-cloud sequences, extending attention models to spatiotemporal 3D data.
- Central contribution is multimodal fusion (LiDAR + camera) within a transformer decoder using queries for semantic classes and object tracklets, i.e., an adaptation to a higher-dimensional domain.

## Evidence extracts
- "we propose 4D-Former: a novel method for 4D panoptic segmentation which leverages both LiDAR and image modalities, and predicts semantic masks as well as temporally consistent object masks for the input point-cloud sequence." (Abstract)
- "we propose a novel transformer-based architecture that effectively combines sparse geometric features from LiDAR with dense contextual features from cameras." (Section 3 Multimodal 4D Panoptic Segmentation)
