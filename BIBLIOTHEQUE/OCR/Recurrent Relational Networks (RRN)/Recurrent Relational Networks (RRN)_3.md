## Core reasons

[2017]'s relational network, it can augment any neural network model with the capacity to do many-step relational reasoning." (Abstract)
- "The dependence on the previous node hidden state  $h_j^{t-1}$  allows the network to iteratively work towards a solution instead of starting with a blank slate at every step." (2 Recurrent Relational Networks)
