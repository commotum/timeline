# RobustFill: Neural Program Learning under Noisy I/O (2017)
Source: RobustFill- Neural Program Learning under Noisy I-O.md

## Core reasons
- Proposes a modified attentional RNN mechanism (with multi-attention and pooling) to encode variable-sized sets of I/O examples for program synthesis, i.e., a computation mechanism for program learning.
- Frames and contrasts program synthesis vs. program induction as alternative neural computation strategies for producing outputs from I/O examples.

## Evidence extracts
- "Our neural models use a modified attention RNN to allow encoding of variable-sized sets of I/O pairs." (Abstract)
- "In the program synthesis approach, we train a neural model which takes  $(I_1, O_1), ..., (I_n, O_n)$  as input and generates P as output, token-by-token." (Section 3.1. Problem Formulation)
