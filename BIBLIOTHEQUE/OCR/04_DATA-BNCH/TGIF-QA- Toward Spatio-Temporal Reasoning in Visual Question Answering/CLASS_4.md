# TGIF-QA: Toward Spatio-Temporal Reasoning in Visual Question Answering (2017)
Source: TGIF-QA- Toward Spatio-Temporal Reasoning in Visual Question Answering.md

## Core reasons
- The paper's primary contributions are a new video VQA dataset and task suite intended to serve as a benchmark for spatio-temporal reasoning.
- The dataset scale, collection process, and task definitions are central, while modeling is presented as a baseline evaluation.

## Evidence extracts
- "First, we propose three new tasks designed specifically for video VQA, which require spatio-temporal reasoning from videos to answer questions correctly. Next, we introduce a new large-scale dataset for video VQA named TGIF-QA that extends existing VQA work with our new tasks." (Abstract)
- "Our dataset consists of 165,165 QA pairs collected from 71,741 animated GIFs." (Section 3. TGIF-QA Dataset)
