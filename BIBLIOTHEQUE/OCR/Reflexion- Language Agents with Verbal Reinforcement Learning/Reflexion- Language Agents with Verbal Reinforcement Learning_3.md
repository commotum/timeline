## Core reasons
- Proposes a verbal reinforcement framework that changes how agents learn from trial-and-error by using linguistic feedback and reflection instead of weight updates.
- Defines an Actor/Evaluator/Self-Reflection loop with episodic memory to guide future decisions, i.e., a new computation and reasoning mechanism for language agents.

## Evidence extracts
- "We propose *Reflexion*, a novel framework to reinforce language agents not by updating weights, but instead through linguistic feedback." (Abstract)
- "The Self-Reflection model instantiated as an LLM, plays a crucial role in the Reflexion framework by generating verbal self-reflections to provide valuable feedback for future trials." (Section "Reflexion: reinforcement via verbal reflection")
