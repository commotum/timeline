# Text and Code Embeddings by Contrastive Pre-Training (Not specified in the paper.)
Source: Text and Code Embeddings by Contrastive Pre-Training.md

## Core reasons
- Proposes a contrastive pre-training method for learning text and code embeddings from unlabeled paired data, which is a training/representation learning contribution rather than a positional encoding or dimensional adaptation.
- Emphasizes model initialization and large-batch contrastive learning as the key recipe for improved representations, fitting ML methodology and principles.

## Evidence extracts
- "we show that contrastive pre-training on unsupervised data at scale leads to high quality vector representations of text and code." (Abstract)
- "In this work, we train embedding models using a contrastive learning objective with in-batch negatives (Sohn, 2016; Yih et al., 2011) on unlabeled data." (Section 1. Introduction)
