# Addressing Function Approximation Error in Actor-Critic Methods (2018)
Source: Twin Delayed DDPG (TD3).md

## Core reasons
- Proposes algorithmic changes to actor-critic reinforcement learning to reduce function approximation error and overestimation bias, which is a training/optimization contribution rather than data or positional encoding.
- Introduces the TD3 algorithm as a modified actor-critic method and evaluates its performance on continuous control tasks.

## Evidence extracts
- "we show that this problem persists in an actor-critic setting and propose novel mechanisms to minimize its effects on both the actor and the critic." (Abstract)
- "Taken together, these improvements define our proposed approach, the Twin Delayed Deep Deterministic policy gradient algorithm (TD3)" (Conclusion)
