# Estimating the Hessian by Back-propagating Curvature (2012)
Source: Estimating the Hessian by Back-propagating Curvature.md

## Core reasons
- Proposes Curvature Propagation to compute unbiased Hessian estimates efficiently, a methodological/optimization contribution.
- Focuses on Hessian estimation for neural network objectives and optimization, not on positional encoding, transformers, or datasets.

## Evidence extracts
- "In this work we develop Curvature Propagation (CP), a general technique for efficiently computing unbiased approximations of the Hessian of any function that is computed using a computational graph." (Abstract)
- "we build upon this idea and develop a family of algorithms, which we call Curvature Propagation (CP), for efficiently computing unbiased estimators of the Hessians of arbitrary functions." (1. Introduction)
