# LIVEBENCH: A CHALLENGING, CONTAMINATION-LIMITED LLM BENCHMARK (Not specified in the paper.)
Source: LiveBench- A Challenging, Contamination-Free LLM Benchmark.md

## Core reasons
- Introduces LiveBench as a new LLM benchmark designed to mitigate test set contamination and judging/crowdsourcing pitfalls.
- Emphasizes benchmark construction and evaluation criteria (frequently updated questions, objective ground-truth scoring, diverse tasks).

## Evidence extracts
- "In this work, we introduce a new benchmark for LLMs designed to be resistant to both test set contamination and the pitfalls of LLM judging and human crowdsourcing." (Abstract)
- "We release LiveBench, the first benchmark that (1) contains frequently-updated questions from recent information sources, (2) scores answers automatically according to objective ground-truth values, and (3) contains a wide variety of challenging tasks, spanning math, coding, reasoning, language, instruction following, and data analysis." (Abstract)
