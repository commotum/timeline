# Segment Anything (2023)
Source: Segment Anything.md

## Core reasons
- Introduces a new promptable segmentation task and the Segment Anything Model for image segmentation, which is a modeling/task contribution.
- Describes a specific architecture (image encoder, prompt encoder, mask decoder) to produce segmentation masks from prompts.

## Evidence extracts
- "We introduce the Segment Anything (SA) project: a new task, model, and dataset for image segmentation." (Abstract)
- "a powerful image encoder computes an image embedding, a prompt encoder embeds prompts, and then the two information sources are combined in a lightweight mask decoder that predicts segmentation masks." (Section 3. Segment Anything Model)
