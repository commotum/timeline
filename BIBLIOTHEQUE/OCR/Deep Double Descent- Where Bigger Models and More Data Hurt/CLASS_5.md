# DEEP DOUBLE DESCENT: WHERE BIGGER MODELS AND MORE DATA HURT (Not specified in the paper.)
Source: Deep Double Descent- Where Bigger Models and More Data Hurt.md

## Core reasons
- Proposes a generalized double descent hypothesis and an effective model complexity measure to explain non-monotonic generalization behavior, which is a foundational ML principle rather than a new model mechanism.
- Focuses on empirical characterization of how model size, training time, and sample size affect test error, rather than introducing datasets/benchmarks or positional encodings.

## Evidence extracts
- "We unify the above phenomena by defining a new complexity measure we call the *effective model complexity* and conjecture a generalized double descent with respect to this measure." (Abstract)
- "We introduce a generalized double descent hypothesis: models and training procedures exhibit atypical behavior when their Effective Model Complexity is comparable to the number of train samples." (Section 8 Conclusion and Discussion)
