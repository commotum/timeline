## Core reasons
- Proposes and improves a neural program induction mechanism that combines discrete operations with neural computation for multi-step reasoning over tables.
- Focuses on changing how computation happens (inducing programs and handling weak supervision for program execution) rather than data resources or positional encodings.

## Evidence extracts
- "Neural Programmer (Neelakantan et al., 2016) is a neural network augmented with a set of discrete operations. It produces both a program, made up of those operations, and the result of running the program against a given table." (Section 1 Background and Introduction)
- "We modify the training objective of Neural Programmer to handle the supervision signal available in real-world settings." (Section 2.3 Training Objective)
