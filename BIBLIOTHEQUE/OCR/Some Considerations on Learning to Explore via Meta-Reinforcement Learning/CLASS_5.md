## Evidence extracts
- "This interpretation leads to the development of two new meta-reinforcement learning algorithms: E-MAML and E-RL<sup>2</sup>." (Abstract)
- "In this paper, we derive an algorithm for gradient-based meta-learning that explicitly optimizes the pertask sampling distributions during adaptation with respect to the expected future returns produced by it post-adaptation self. This algorithm is closely related to the recently proposed MAML algorithm [7]. For reasons that will become clear later, we call this algorithm E-MAML. Inspired by this algorithm, we develop a less principled extension of RL<sup>2</sup> that we call E-RL<sup>2</sup>." (1 Introduction)
