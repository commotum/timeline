## Core reasons
- Proposes augmenting recurrent nets with structured, trainable memory (stack/list) to learn algorithmic patterns beyond standard RNN capabilities.
- Defines explicit memory control operations (e.g., PUSH/POP) that change how computation proceeds, targeting counting and memorization limits.

## Evidence extracts
- "We attempt to increase the learning capabilities of recurrent nets by allowing them to learn how to control an infinite structured memory. We explore two basic topologies of the structured memory: pushdown stack, and a list." (Section 1 Introduction)
- "We have shown that certain difficult pattern recognition problems can be solved by augmenting a recurrent network with structured, growing (potentially unlimited) memory." (Section 7 Conclusion)
