## Summary
The paper covers synthetic causal structure learning on tabular feature matrices and multi-omics downstream tasks including gene perturbation prediction, cell type annotation, cell clustering, and DNA methylation age prediction. Inputs are described as tabular non-sequential feature matrices or per-cell feature vectors, so task dimensions are inferred as 2D for causal graph recovery and 1D for per-sample tasks, with outputs ranging from 2D adjacency matrices to 1D expression profiles or 0D labels/ages. For transformer-based tasks, attention is inferred as Static and state as Constructed based on the use of self-attention and contextualized/aggregated embeddings, while interface dynamics are treated as Fixed where matrix sizes or fixed feature sets are described.
